## P1. 박지수 — ESG 팀장 (Primary)
- **나이/경력**: 42세 / 15년차
- **조직**: 자산 5조원 제조 대기업, ESG팀 6명
- **목표 (JTBD)**:
  - "EU CSRD 의무공시를 정확하게, 늦지 않게 제출한다"
  - "이사회·투자자에 임팩트 스토리를 신뢰성 있게 전달한다"
- **핵심 활동**: 데이터 수집 조율, 외부 검증 대응, 이사회 보고
- **페인 포인트**:
  - 9개 부서 데이터를 엑셀로 받아 수작업 통합
  - GRI/TCFD/ESRS 매핑이 분기마다 반복
  - 외부 컨설팅 비용이 연간 수억
- **얻고 싶은 것 (Gains)**: 자동 매핑, 단일 데이터 허브, 변경 추적
- **사용 빈도**: 매일
- **결정 권한**: 도구 도입 추천 → 임원 승인
- **주요 사용 시나리오**: 분기 보고 사이클, 외부 ESG 평가 응답

## P2. 김민호 — 지속가능성 매니저 (Primary)
- **나이/경력**: 34세 / 8년차
- **조직**: 매출 3,000억 IT 서비스 기업, 지속가능성 1인 담당
- **목표 (JTBD)**:
  - "1인 인력으로도 글로벌 표준 보고서를 만든다"
  - "경영진에게 ESG ROI를 설득한다"
- **페인 포인트**:
  - 도구 예산 한정, Watershed 같은 고가 솔루션 도입 불가
  - 보고서 작성 노하우 부족
  - SDG·GRI·SASB 차이를 매번 학습
- **Gains**: AI 보조, 템플릿, 학습 콘텐츠
- **결정 권한**: $20K 이하 자체 결정 가능
- **선호 채널**: 자가가입 → 무료 트라이얼 → 결제

## P3. 이서연 — CFO/IR 디렉터 (Secondary, Buyer)
- **나이/경력**: 48세 / 22년차
- **조직**: 시총 1조 코스피 상장사
- **목표**:
  - "ESG 공시 리스크를 최소화한다"
  - "투자자 ESG 평가 점수를 올린다"
- **페인 포인트**:
  - 공시 오류 시 법적·평판 리스크
  - 데이터 출처 추적 어려움
- **Gains**: 감사 추적, 공시 통제, 외부 평가 향상
- **결정 권한**: $100K+ 예산 결정자
- **검토 항목**: 보안 인증, SLA, 레퍼런스

- **조직**: 글로벌 NGO 한국지부
- **목표**:
