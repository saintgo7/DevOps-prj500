## P6. Aisha — 현지 SDG 챔피언 (Primary, 누락되었던 핵심 페르소나)
- **나이/배경**: 28세, 우간다 캄팔라 외곽, 현지 NGO 4년 경력, 영어·스와힐리·루간다어
- **조직**: 직원 5명, 공여자 의존 NGO. 인터넷·노트북 1대 공유.
- **목표 (JTBD — 가장 근본적 동기)**:
  - "내 공동체의 SDG 실천이 *외부에서 들여오는 것이 아니라 우리가 주도하는 것*임을 증명하고 싶다"
  - "전 세계에서 같은 고민을 하는 동료를 만나 배움을 주고받고 싶다"
  - "공여자에게 우리 활동을 정량으로 보여 자금을 직접 받고 싶다 (Grand Bargain 25% 약속)"
- **페인 포인트**:
  - SDG 169 Target·232 Indicator를 모국어로 학습할 자료가 거의 없음
  - 글로벌 ESG 도구는 가격·UI·보안 인증 요구가 너무 높음 (P1·P2 대상으로 설계됨)
  - 현장 데이터 입력 = 모바일·저대역폭·간헐 인터넷
  - 공여자 보고서는 항상 영어, 본인 공동체 언어로는 노력해도 작성 가능
  - 정작 같은 도전에 직면한 다른 LDC 활동가와 만날 채널이 거의 없음
  - "도움받는 대상"으로만 보이는 것에 대한 자기존엄 침해
- **얻고 싶은 것 (Gains)**:
  - 모국어/지역 공용어 (스와힐리·하우사·아랍어·프랑스어·포르투갈어 등) UI
  - 모바일 우선·오프라인 작동·저데이터 모드
  - **Peer Matching** — 비슷한 고민·상황의 다른 챔피언과 연결
  - 본인 데이터·이야기의 소유권 (데이터 식민주의 회피)
  - 무료 또는 NGO/LDC 0원 티어
- **사용 빈도**: 주 3-4회, 모바일 70% / 데스크톱 30%
- **결정 권한**: 자기 조직 내 도구 도입 자체 결정
- **주요 사용 시나리오**:
  - 공여자 분기 보고서 (영어) + 공동체 통신 자료 (스와힐리) 동시 생성
  - 같은 SDG·지역에서 일하는 다른 NGO와 데이터·교훈 공유
  - 현장 인터뷰 음성을 즉석 텍스트화 (저대역폭·다국어 STT)

### P6의 7가지 본질적 차별 요구
1. **모국어 + 지역 공용어** (영어 강제 X)
2. **모바일 퍼스트 + 오프라인 모드**
3. **0원/저가 티어 (LDC 자동 적격)**
4. **데이터 주권** — 본인이 소유, 공여자에게 공개 범위 직접 선택
5. **Peer Match** — 글로벌 동료와의 직접 연결
6. **Mentor Match** — 자원 풍부한 P1·P4가 시간을 기부할 채널
7. **자기존엄 카피 톤** — "수혜자" "지원 대상" 같은 시혜적 표현 금지
