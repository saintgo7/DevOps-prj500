# ADR-0003: Claude를 1차 LLM 공급자로 채택한다

- 상태: Accepted
- 일자: 2026-04-25
- 작성자: AI Lead
- 관련 문서: `docs/12-tech-stack.md`, `docs/15-security-design.md`

## 컨텍스트
SDG 매핑 추천, 보고서 초안 생성, 문서 추출 등 LLM 의존도가 높다. 정확도·긴 컨텍스트·인용·도구 사용·캐싱·안전성·아시아 시장 데이터 처리 위치가 핵심 기준이다.

## 결정
**Anthropic Claude를 1차 공급자**로 채택한다:
- 보고서 생성·복합 추론: `claude-opus-4-7`
- 매핑 추천: `claude-sonnet-4-6`
- 단순 요약·라벨링: `claude-haiku-4-5-20251001`

운영 패턴:
- 모든 호출은 `apps/ai` (FastAPI) AI Gateway 경유
- 시스템 프롬프트 + SDG 카탈로그는 **Prompt Caching** (1h TTL)
- Tool Use로 데이터 조회·계산·인용 도구 등록
- 출력에는 **Citations** 표기 필수
- 페일오버: AWS Bedrock Claude (동일 모델군)

## 근거
- 긴 컨텍스트 (SDG 카탈로그 + 사용자 데이터) 처리 우수
- 캐싱·도구·인용 일등급 지원으로 비용·신뢰성 동시 달성
- Bedrock 경유 옵션으로 가용성·데이터 위치 옵션 확보
- 안전성·정렬 평판

## 결과
- (+) 보고서 품질, 비용 효율(캐싱), 인용으로 신뢰성
- (-) 단일 공급자 의존 → Bedrock 경유로 완화
- 위험: 모델 변경(예: 4.6 → 4.7) 회귀 → 평가 셋 1,000건 회귀 테스트

## 대안
| 대안 | 장점 | 단점 | 기각 사유 |
|------|------|------|----------|
| OpenAI 1차 | 광범위 도구 | 긴 컨텍스트·캐싱·인용 약함 | 본 도메인에 적합도 낮음 |
| 멀티프로바이더 라우팅 | 가격·가용성 | 프롬프트 일관성 깨짐, 평가 비용 N배 | 초기엔 비용·복잡도 큼 |
| 자체 호스팅 OSS | 비용·데이터 통제 | 품질·운영 부담 | 도메인 정확도 미달 |

## 후속 액션
- [ ] AI Gateway 인터페이스(추후 멀티 공급자 가능 설계)
- [ ] 평가 셋 v1 (1,000건) 라벨링
- [ ] 모델 변경 시 회귀 테스트 자동화
- [ ] Prompt Caching 적중률 대시보드
