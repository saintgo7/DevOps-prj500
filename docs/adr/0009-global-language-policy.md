# ADR-0009: 글로벌 언어 정책 — Top-10 + LDC 우선

- 상태: Accepted
- 일자: 2026-04-25
- 작성자: Product / UX Lead
- 관련 문서: `docs/06-personas.md` (P6), `docs/10-ux-design-system.md`

## 컨텍스트
초기 ADR (i18n 일반)에서 ko/en/ja/zh 4개 언어로 시작했다. 그러나 SDG 실현은 본질적으로 **글로벌 형평성** 문제이며, 4개 언어로는 다음 인구가 모두 서비스에서 배제된다:

- 인도·방글라데시·스리랑카 (Hindi, Bengali — 약 9억 명)
- 라틴아메리카·이베리아 (Spanish, Portuguese — 약 8억 명)
- 22개 아랍 국가 (Arabic — 3억+, RTL 포함)
- 사하라이남 32개 LDC 중 14개국 (French 공용어)
- 동아프리카 8개국 EAC (Swahili 공용어, 2억+)
- 5억+ 러시아·CIS·중앙아시아
- 2.5억+ 인도네시아

특히 UN LDC 44개국의 **현지 활동가 (페르소나 P6)** 가 자기 모국어로 도구를 쓰지 못하면, 본 SaaS는 "선진국이 후진국에 들고 가는 도구"가 되어 SDG 17 (파트너십)·10 (불평등 감소)·16.7 (포용적 의사결정)에 직접 반한다.

| 코드 | 언어 | 선정 사유 |
|------|------|----------|

| zh | 简体中文 | 1.18B (Mandarin) |

| es | Español | 558M (라틴아메리카) |

| fr | Français | 312M (서·중앙아프리카 LDC 14개) |
| bn | বাংলা | 284M (방글라데시 LDC) |
| pt | Português | 266M (앙골라·모잠비크 LDC) |

| sw | Kiswahili | 200M+ (EAC 8개국, 동아프리카 LDC 다수) |

총 커버리지: **세계 인구 약 75% + UN LDC 44개국 중 약 35개국의 공용·실사용 언어**.

**RTL 지원**: `dir="rtl"` 자동 적용 (`apps/web/src/i18n/routing.ts` `RTL_LOCALES`), 디자인 토큰은 mirror-safe 검증 필수.

**가격 정책**: 본 결정과 함께 `docs/04-business-model.md`에 **LDC/NGO 0원 티어**가 추가된다 (별도 ADR-0010 또는 BMC 갱신).

## 근거
- Ethnologue 2025: 13개 언어 = 인구 75% 도달
- IWGIA 2025: SDG 풀뿌리 참여의 가장 큰 장벽 1위는 "**언어**"
- USAID 25%/실제 12%, Grand Bargain 미달 — 도구가 영어 중심이면 현지 자금 직접 수령은 구조적으로 불가
- 본 프로젝트 SDG 4·10·16.7·17과 직접 정렬

## 결과
- (+) 70억+ 인구가 모국어로 SDG 도구 접근 가능
- (+) LDC 현지 활동가 페르소나 P6에 적합한 도구로 변모
- (-) 운영 부담: 13개 카탈로그 동기화 + 번역 품질 관리
  - 완화: 표준 SDG 텍스트는 UN 공식 번역 활용 (저작권 CC BY 3.0 IGO)
  - 완화: 사용자 향 UI 카피만 자체 번역, 분기 전문 검수
- (-) 번역 누락 시 fallback 체인 필요
  - 결정: 요청 → en → ko → ja → zh → 첫 사용 가능 (이미 `localized()`에 구현)

## 대안 (기각)
| 대안 | 기각 사유 |
|------|----------|
| 영어만 + 자동번역 | SDG 16.7에 반함, 공식 번역 신뢰성 < 인간 번역 |
| 4개 언어 (ko/en/ja/zh) | 사하라이남·아랍권·라틴아메리카·남아시아 전체 배제 |
| 30개 언어 일괄 | 운영·검수 비용 비현실적, 단계적 접근 |
