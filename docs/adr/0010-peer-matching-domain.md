# ADR-0010: Peer Matching — 같은 고민을 하는 인류를 잇는다

- 상태: Accepted
- 일자: 2026-04-25
- 작성자: Product Owner / Architect
- 관련 문서: `docs/06-personas.md` (P6), `docs/03-sdg-framework.md`, `docs/15-security-design.md` (AI 보안)

## 컨텍스트
조사 결과(Civic Match, Local2030, IWGIA 2025), SDG 임팩트의 가장 큰 가속 요인은 *도구의 정교함*보다 **"같은 고민을 하는 사람을 알아보고 잇는 것"** 이다.

본 SaaS는 현재 도구(매핑·보고서)에만 집중되어 있어, 두 가지 결정적 가치가 빠져 있다:

1. **Peer Match (동료 매칭)** — 비슷한 SDG·지역·도전을 가진 활동가가 서로 만나 배움·자료·운영 패턴을 공유
2. **Mentor / Funder Bridge** — 자원 풍부한 P1/P3/P4 인격과 자원 부족한 P6 인격이 서로 인지·신뢰·자금/시간을 흘려보낼 채널

기존 시장: Civic Match, Idealist, Catchafire는 일반 비영리 매칭에 그침. SDG 169 Target × 232 Indicator × 다국어 컨텍스트 매칭은 공백.

## 결정
**Peer Matching을 본 SaaS의 1급 도메인으로 추가한다.**

### 도메인 모델 (요약)
새 엔터티 (`docs/13` 갱신 예정):
- `MatchProfile` — 사용자별 자기 선언: SDG 관심·역량·언어·지역·역할 (실천자/멘토/공여자)
- `MatchSignal` — Like / Save / Connect / Skip — 학습 신호
- `MatchPair` — 양측 동의로 형성된 연결, 메시징·공유 권한
- `LearnedAffinity` — pgvector 임베딩 (관심·언어·SDG 다중 매핑)

### 매칭 알고리즘
1. **Vector similarity**: 자기 선언 텍스트 + 활동 이력 임베딩 (BGE-M3 다국어)
2. **Hard filters**: 언어 호환성 (최소 1개 공통), SDG 1개 이상 겹침, 역할 보완 가능
3. **Diversity**: 같은 국가 매칭 비율 30% 상한 (글로벌 다양성)
4. **Equity weight**: P6 (LDC 현지 실천자) 매칭 추천 시 추가 가중 — 가시성 격차 보정
5. **AI 추천 사유**: Claude가 "왜 이 사람과 만나야 하는지" 1-2문장 생성, 인용 표기

### 워크플로우
```
사용자: 자기 선언 (SDG · 언어 · 역할 · 한 줄 소명)
   ↓
시스템: 주간 5명 매칭 카드 (다국어 자동 번역)
   ↓
양측 Connect 클릭 시
   ↓
Match 형성 → 비동기 메시징 (도구 내) + 선택적 화상 일정
```

### 안전 통제
- 신원: 최소 이메일 검증 + 선택적 KYC (Persona 기반)
- 메시지 처음 5회는 PII 자동 마스킹 표시 (스팸·사기 방지)
- 신고 / 차단 / 평판 점수 1급
- 미성년자 자동 거부 (18+ 약관)
- 모든 매칭 행위 감사로그 (`docs/15`의 7년 보존)

### AI 보안 (필수)
- 매칭 추천 사유는 **인용 의무** (자기 선언 + 활동 이력 인용)
- Prompt injection 방어 (자기 선언에 시스템 프롬프트 주입 시도 차단)
- 환각 방지 — 추천 사유는 실제 데이터에서만 인용
- AI 결정만으로는 매칭 자동 형성 X — 최종 클릭은 인간 (4-eyes 원칙 변형)

### 데이터 주권 (P6 필수)
- 자기 선언·매칭 이력의 소유는 **사용자**
- 공개 범위는 사용자가 선택 (전체/지역/연결된 사람만)
- 30일 내 익명화 + 90일 내 완전 삭제 가능
- 데이터 식민주의 회피: P6 데이터를 P1·P3가 학습 데이터로 사용 X (별도 동의 필요)

## 근거
- Civic Match·Local2030 사례에서 Peer Matching의 임팩트 증명
- USAID 25%·Grand Bargain 25% 미달의 본질 = 글로벌 사우스 활동가의 가시성·관계 자본 부족
- 본 SaaS 자체의 SDG 17 (파트너십) 직접 기여
- 페르소나 P6 (현지 챔피언)에 가장 결정적 가치

## 결과
- (+) 본 SaaS가 "보고서 도구"에서 "**SDG 글로벌 시민 네트워크**"로 진화
- (+) Network effect → Lock-in → LTV 확대
- (+) GTM 채널 자체 확장 (P6가 P1/P3에 새 고객 유입)
- (-) 메시징·신뢰 안전 운영 부담 (분기 1회 콘텐츠 모더레이션 리뷰)
- 위험: 매칭 알고리즘 편향 → 가시성 격차 강화 가능
  - 완화: Equity weight, 다양성 강제, 분기 공정성 감사

## 대안 (기각)
| 대안 | 기각 사유 |
|------|----------|
| 외부 (Civic Match·Slack) 링크만 제공 | 데이터·관계가 본 SaaS에 안 남아 SDG 임팩트 측정 불가 |
| 단순 Directory (검색만) | "발견" 없음, 불공정한 가시성 |
| 자동 매칭 (양측 동의 X) | 신뢰·안전 침해, 자기존엄 침해 |
