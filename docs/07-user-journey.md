# 07. 사용자 여정 지도 (User Journey Map)

## 1. 핵심 여정 (P1: ESG 팀장 박지수, 분기 보고 사이클)

### Stage 1. Awareness — 도구 인지
- **터치포인트**: ESG 컨퍼런스, 동료 추천, Google "ESG 보고서 도구"
- **생각**: "Watershed는 너무 비싸. 한국어 되는 게 있을까?"
- **감정**: 😟 부담
- **기회**: 한국어 콘텐츠, 비교 콘텐츠, 사례 연구

### Stage 2. Consideration — 평가
- **터치포인트**: 웹사이트, 데모 신청, 영업 미팅
- **할 일**: 가격·보안·기능 비교, 보안팀 검토 의뢰
- **감정**: 🤔 신중
- **이탈 사유**: 데모 일정 지연, 보안 자료 부족, 가격 미공개
- **기회**: Self-serve 데모, 보안 화이트페이퍼, 가격 투명

### Stage 3. Onboarding — 설정
- **0일차**: 계정 생성, 조직 정보 입력, 기존 데이터 임포트(Excel/CSV)
- **3일차**: 활동·메트릭 정의, 부서 사용자 초대
- **7일차**: 첫 데이터 입력 사이클, AI 매핑 추천 검토
- **30일차**: 첫 분기 데이터 완성
- **감정**: 🚀 → 😅 (러닝커브) → 😌
- **기회**: 가이디드 투어, 템플릿 라이브러리, 전담 CSM (Enterprise)

### Stage 4. Active Use — 분기 보고
- **W1**: 부서별 데이터 수집 요청 발송
- **W2**: 데이터 검토·검증
- **W3**: AI 보고서 초안 생성, 도메인 전문가 리뷰
- **W4**: GRI/TCFD/ESRS 자동 매핑 검토, 임원 승인
- **W5**: 외부 공시·홈페이지 발행
- **감정**: 시간 단축에 만족 ⭐️
- **기회**: Workflow 자동화, 알림, 코멘트·승인 시스템

### Stage 5. Renewal & Expansion
- **시점**: 11개월차 갱신 논의
- **고려**: 추가 모듈 (탄소회계, 공급망), 사용자 확장
- **감정**: ROI 입증 시 만족, 미입증 시 가격 협상
- **기회**: QBR, ROI 대시보드, 사례 공유

## 2. 핵심 사용자 흐름 (UX Flows)

### 2.1 Activity → SDG 매핑
```
1. [활동 입력] (제목, 설명, 데이터)
2. [AI 분석] Claude가 SDG 후보 3개 + 신뢰도 제시
3. [검수] 담당자가 후보 선택/수정/추가
4. [Evidence 첨부] 파일/URL/노트
5. [지표 정량화] 단위·값 입력
6. [저장] 감사로그 기록
```

### 2.2 Report 생성
```
1. [기간 선택] 분기/반기/연간
2. [표준 선택] GRI / TCFD / ESRS / K-ESG (다중)
3. [범위 선택] 조직 단위, 사업부
4. [AI 초안] Claude가 표준별 보고서 초안 생성 (5-10분)
5. [검토 모드] 단락별 코멘트, 인용 확인
6. [승인] 결재선 따라 승인
7. [발행] PDF/HTML/iXBRL 출력
```

### 2.3 데이터 수집 워크플로우
```
1. [요청 정의] 누구에게, 어떤 데이터, 언제까지
2. [발송] 이메일 + 인앱 알림
3. [입력] 부서 담당자가 폼/엑셀 업로드
4. [검증 규칙] 단위·범위·완전성 자동 체크
5. [승인] ESG팀 검수 → 잠금
```

## 3. 페인 포인트 & 기회 매트릭스
| 단계 | 주요 페인 | 기회 | 우선순위 |
|------|----------|------|---------|
| Awareness | 한국어 콘텐츠 부재 | 블로그·웨비나 | High |
| Consideration | 가격·보안 불투명 | 공개 가격, 화이트페이퍼 | High |
| Onboarding | 데이터 임포트 어려움 | 임포트 위저드, 템플릿 | Critical |
| Active Use | 부서간 데이터 추적 | 워크플로우·알림 | Critical |
| Active Use | AI 환각 | 인용·신뢰도 노출 | Critical |
| Renewal | ROI 입증 어려움 | 시간 절약 대시보드 | High |

## 4. 이탈 위험 신호 (Churn Signals)
- 30일 후 활성 사용자 < 3명
- 분기 보고서 미생성
- AI 매핑 정확도 사용자 만족도 < 3/5
- 데이터 입력 빈도 급감

## 5. 측정 지표 (Per Stage)
| 단계 | 지표 |
|------|------|
| Awareness | 웹사이트 방문, 콘텐츠 다운로드 |
| Consideration | 데모 신청, 보안 자료 요청 |
| Onboarding | TTV (Time-to-First-Value), 7일 활성 |
| Active Use | 월간 활성 사용자, 보고서 생성 수 |
| Renewal | NRR, 갱신율, 확장 ARR |

## 6. 다중 페르소나 인터랙션
- **P1 (팀장)**: 워크플로우 설계·승인
- **P2 (담당자)**: 일상 데이터 입력
- **P3 (CFO)**: 임원 대시보드 조회
- **P5 (보안)**: 감사로그·접근 통제 검토
- 모든 화면은 역할 기반 권한(RBAC) 적용
