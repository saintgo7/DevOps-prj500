# 01. 프로젝트 헌장 (Project Charter)

## 1. 프로젝트명
**SDG Impact Cloud** — UN 지속가능발전목표(SDGs) 기반 임팩트 측정·보고 SaaS

## 2. 비전
"모든 조직이 자신의 활동을 SDG로 측정하고, 신뢰할 수 있는 데이터로 세상을 바꾸도록 한다."

## 3. 목적 (Mission)
- 분산된 ESG/임팩트 데이터를 표준 SDG 지표로 통합
- 글로벌 보고 표준(GRI·SASB·TCFD·ESRS·K-ESG)에 자동 정합화
- AI를 통해 활동→SDG 매핑·보고서 초안 생성 시간을 90% 단축

## 4. 범위 (Scope)
### In Scope
- 17개 SDG / 169개 세부목표 / 232개 공식 지표 데이터 모델
- 멀티테넌시 SaaS, 한·영·일 다국어
- AI 기반 활동-SDG 매핑, 보고서 초안 생성
- 외부 시스템 연동 (ERP, HR, 회계, IoT 센서)

### Out of Scope (v1)
- 블록체인 기반 검증·NFT 인증서
- 온오프라인 컨설팅 직접 제공 (파트너 위탁)
- 탄소배출권 거래소 기능

## 7. 주요 산출물 (Deliverables)
- 21개 기획·설계 문서 (본 프로젝트의 docs/ 디렉터리)
- MVP SaaS (웹 애플리케이션 + API)
- 운영 매뉴얼 및 SRE 런북
- 파일럿 사례 리포트 3건

## 8. 일정 (High-Level Timeline)
- **M1 (Mo 1-3)**: 21개 문서 작성 완료, 백로그 확정
- **M2 (Mo 4-6)**: MVP 개발 (Alpha)
- **M3 (Mo 7-9)**: 파일럿 운영 (Beta)
- **M4 (Mo 10-12)**: GA 출시 및 GTM 본격화

## 9. 예산 가정
- 인건비 6명 × 12개월 (FE 2, BE 2, DevOps 1, PM 1)
- 인프라 AWS 월 $3-8K (트래픽 증가 시 탄력적)
- AI API 비용 (Claude Opus/Sonnet) 월 $1-3K
- 외부 컨설팅·법무·디자인 별도

## 10. 가정 (Assumptions)
- UN SDG Indicator 데이터(232 지표)는 공개되어 있으며 자유롭게 사용 가능
- 초기 시장은 한국·일본·EU의 ESG 의무공시 대상 기업
- 인증·감사는 v1.5 이후 별도 모듈

## 11. 제약 (Constraints)
- EU CSRD 발효 일정에 맞춘 Q3 2026 GA
- 개인정보·민감 ESG 데이터는 EU/KR 리전 분리 보관
- 접근성 WCAG 2.2 AA 의무

## 12. 리스크 요약 (Top 5)
1. SDG 매핑 정확도 부족으로 인한 신뢰도 하락 → 도메인 전문가 검수 워크플로우 필수
2. 규제(CSRD/K-ESG) 변경 → 분기별 컴플라이언스 리뷰 정례화
3. 경쟁사(Watershed, Novata 등) 빠른 진입 → 다국어·아시아 시장 우선 차별화
4. AI 환각으로 인한 잘못된 보고서 → 인간 검수 게이트 필수
5. 멀티테넌시 데이터 누수 → 보안설계 문서(15)에서 별도 위협모델링
