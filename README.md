## 📋 Project Overview

This repository contains **500 complete, executable programs** across 5 major categories, created using the **Vibe Coding** methodology with **Claude Code**. Each program is designed as a standalone learning resource with comprehensive documentation, tests, and examples.

### 🎯 Goals

- **Total Programs**: 500
- **Naming Convention**: `01_program_name`, `02_program_name`, etc.
- **Development Tool**: Claude Code (CLI)
- **Approach**: Vibe Coding - Fast prototyping with AI collaboration

## 🚀 Quick Start

### Prerequisites

- **Python**: 3.11+
- **Node.js**: 18+
- **C++ Compiler**: GCC 11+ or Clang 14+
- **Unity**: 2022+ (for game programs)
- **Git**: Latest version

### Clone Repository

```bash
git clone https://github.com/saintgo7/DevOps-prj500.git
cd DevOps-prj500
```

### Run a Python Program

```bash
cd 01-100_Python/01_hello_world
python main.py
```

### Run a C++ Program

```bash
cd 101-200_CPP/101_hello_cpp
mkdir build && cd build
cmake ..
make
./hello_cpp
```

### Run a Web App

```bash
cd 201-300_WebApp_Mobile/231_react_hello
npm install
npm start
```
