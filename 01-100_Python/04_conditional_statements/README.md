## 💡 Key Concepts

### If Statements
```python
if condition:
    # Execute if condition is True
```

### If-Else
```python
if condition:
    # Execute if True
else:
    # Execute if False
```

### If-Elif-Else
```python
if condition1:
    # First condition
elif condition2:
    # Second condition  
else:
    # Default case
```

### Ternary Operator
```python
result = value_if_true if condition else value_if_false
```

### Match-Case (Python 3.10+)
```python
match value:
    case pattern1:
        # Handle pattern1
    case pattern2:
        # Handle pattern2
    case _:
        # Default case
```
