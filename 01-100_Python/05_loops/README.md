## 💡 Key Concepts

### For Loops
```python
for item in iterable:
    # Process item
```

### While Loops
```python
while condition:
    # Execute while True
```

### Loop Control
```python
break      # Exit loop
continue   # Skip to next iteration  
pass       # Do nothing (placeholder)
```

### Enumerate & Zip
```python
for index, value in enumerate(items):
    # Get index and value

for a, b in zip(list1, list2):
    # Combine iterables
```

### List Comprehension
```python
result = [expression for item in iterable if condition]
```
